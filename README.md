# cse210-warm-up-task-public

This repository exists only to host the GitHub Pages deployment of the private `cse210-warm-up-task` repo.

The source code lives in the private repo. A GitHub Actions workflow there builds the Vite + React app and pushes the compiled output to this repo's `gh-pages` branch, which GitHub Pages then serves.

**Live site:** https://www.maxwei.io/cse210-warm-up-task-public/

> Don't edit this repo directly. The `gh-pages` branch is overwritten on every deploy.
